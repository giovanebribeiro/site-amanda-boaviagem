# Suggested Commands

```sh
npm install          # install deps after clone
npm run dev          # runs next lint (prebuild) then starts dev server on :3000
npm run lint         # run ESLint only (next lint)
npm run build        # production build (outputs to .next/)
npm run start        # serve production build locally on :3000
npm run app          # build + export static output to out/
npm run release      # bump version, update CHANGELOG.md, create git tag (standard-version)
```

No test runner is configured in this project.
